DRIFT

Detection and Reasoning for Identified Fabrication Traces

Fine-grained, zero-shot hallucination detection for Retrieval-Augmented Generation systems.

View GitHub Repository View Research Paper

About DRIFT

Retrieval-Augmented Generation (RAG) systems can still produce unsupported or contradictory information even when relevant evidence has been retrieved. Existing response-level detectors often fail to show which claims are fabricated, or why.

DRIFT addresses this with fine-grained, claim-level verification. It breaks a response into atomic factual units, checks each one against the retrieved evidence, and reports a verdict with the reasoning behind it.

How DRIFT works

A response and its retrieved evidence pass through six stages. Each factual unit, called a DriftSpan, is scored independently.

  1. RAG Response + Retrieved EvidenceInput
  2. DriftSpan DecompositionAtomic factual units
  3. Retrieval AlignmentMatch each span to evidence
  4. Tri-Signal ExtractionThree complementary signals
  5. Drift Index (DI)Per-span score
  6. Claim-Level ClassificationSupported or fabricated
  7. Response Drift Score (RDS)Response-level aggregation

Results were obtained on the full RAGTruth test split: 2,574 samples across six LLMs. DRIFT outperformed all zero-shot baselines, including prompted GPT-4 (F1 = 0.476). Adding cross-chunk contradiction improved recall by 2.94 percentage points.

Project outcome

DRIFT provides:

  • Fine-grained localization of fabricated claims
  • Evidence-based reasoning
  • Interpretable claim-level verdicts
  • Overall response reliability assessment
  • Zero-shot operation without model fine-tuning or access to model internals
